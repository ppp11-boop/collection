# Media checklist

Save each of your records inside the `media/` folder with the exact matching name.

- [ ] `image01-full-roll.jpg` - entire roll before much use
- [ ] `image02-surface.jpg` - close-up of paper texture
- [ ] `image03-first-edge.jpg` - loose or torn edge
- [ ] `sound01-rotation.wav` - roll turning on holder
- [ ] `sound02-tear.wav` - one sheet being torn
- [ ] `text01-written-encounter.txt` - short first-person observation
- [ ] `image04-morning.jpg` - roll in morning light
- [ ] `image05-after-use.jpg` - visible reduction after use
- [ ] `image06-inside-tube.jpg` - view through cardboard centre
- [ ] `image07-one-sheet.jpg` - one separated sheet beside roll
- [ ] `text02-measurement-1.txt` - first remaining-percentage or diameter estimate
- [ ] `image08-halfway.jpg` - approximately half remaining
- [ ] `image09-shadow.jpg` - the roll's shadow
- [ ] `image10-night.jpg` - the roll in artificial night light
- [ ] `text03-measurement-2.txt` - later remaining-percentage or diameter estimate
- [ ] `image11-almost-empty.jpg` - cardboard core clearly visible
- [ ] `image12-last-sheets.jpg` - only several sheets remain
- [ ] `image13-final-sheet.jpg` - last sheet still attached
- [ ] `image14-empty-tube.jpg` - empty cardboard tube
- [ ] `image15-absence.jpg` - empty holder or space after removal

For `.txt` records, write a few honest sentences or measurements and save as plain text. For audio, 5-15 seconds is enough if the sound is clear.
